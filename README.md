# PWN Recovery Agent

Prywatna wtyczka WordPress dla psychologwnecie.pl do odzyskiwania niedokończonych rezerwacji LatePoint.

**Status:** faza 1 (audyt). Wtyczka PWN Recovery Agent nie jest jeszcze implementowana.

- `docs/PHASE-1-AUDIT.md`: wyniki i plan fazy 1, ryzyka, pytania do decyzji.
- `pwn-recovery-audit/`: jednorazowy audytor tylko do odczytu, uruchamiany na instalacji WordPress.

Sekrety (klucz OpenAI itp.) nie trafiają do repozytorium. Będą definiowane w `wp-config.php` lub w zmiennych środowiskowych.
